# Instrucciones del proyecto Bojana Online

Antes de comenzar cualquier tarea relacionada con el Portal de Clientes de Bojana Estudio, consulta el documento `Bojana_Portal_ADN_de_producto_y_sistema_de_interfaz.docx` disponible en Sources y trátalo como la fuente de verdad para el modelo del producto, arquitectura de información, layouts, componentes, estilos, estados, microcopy, responsive, accesibilidad y comportamiento.

Mantén siempre estas decisiones:

- El cliente recorre una historia editorial continua del proyecto, no un dashboard modular.
- El estudio trabaja desde un workspace unificado.
- La estructura es Proyecto → Disciplina → Necesidad → Etapa opcional → Tarea.
- El progreso se calcula mediante tareas y no se modifica manualmente.
- Las acciones del cliente aparecen dentro del flujo y pueden bloquear tareas dependientes.
- Visibilidad, publicación y comunicación son acciones independientes.
- Se reutilizan los componentes, tokens, estados y nombres definidos antes de crear patrones nuevos.
- La interfaz mantiene el lenguaje sobrio, editorial, técnico, monocromático y accesible de Bojana.

Si una solicitud entra en conflicto con la guía, señala el conflicto antes de aplicarla. La instrucción explícita más reciente de la usuaria tiene prioridad para esa tarea.

Cuando se apruebe una excepción o una decisión nueva, indica qué sección del documento maestro debe actualizarse y trata el cambio como una nueva versión del ADN del portal.
